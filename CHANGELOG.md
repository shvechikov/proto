# Изменения метода

## v0.2 · 2026-10-15

По итогам проверки двух проектов, из которых вырос метод, по самому методу.

**Исправлено:**

- `check-docs.mjs` проверяет все AGENTS.md и CLAUDE.md, включая вложенные. Раньше разросшийся файл эксперимента проходил незамеченным. Строки теперь считаются верно.
- Ограждение журнала разрешает править последнюю запись, а не «сегодняшнюю»: одна сессия может идти несколько дней.
- Хук на старте сессии печатает дату и «Сейчас» до следующего заголовка, а не до слова «Дальше».
- Отдельный `identifier` для разработки работает, только если папка данных и запись в связке ключей выводятся из него, а не зашиты константами.

**Изменено:**

- Существующий проект подключается ссылкой на proto с коммитом и таблицей соответствия, без копии `docs/method/`. Копия остаётся только у проектов, начатых по методу.
- «Диалект» переименован в «Отличия от метода».
- В START.md появилась ветка для стека, которого нет в `stacks/`: агент пишет `docs/stack.md` по образцу.

**Добавлено:**

- **Работа и документы:**
  - статус карточки «принято» — эксперимент прижился и стал частью продукта;
  - пределы для карточки: «Сейчас» до десяти строк, журнал версий по строке;
  - не больше десяти открытых вопросов; висящие дольше двух недель закрываются выбором по умолчанию;
  - `docs/issues/` — технический долг с условием «когда вернуться»; `docs/research/` — исследования и справка;
  - документы, которые код раздаёт пользователям, помечаются как рабочее содержимое и закрываются тестом.
- **Безопасность:**
  - резервная копия настоящих данных перед рискованным шагом;
  - старые версии смотреть через `git worktree`;
  - агент не читает токены утилит и не хозяйничает на машине автора.
- **Проверки:**
  - «верни ошибку — тест покраснел» для каждого исправления;
  - фиксированный часовой пояс;
  - общие векторы для логики на двух языках;
  - граница приватности как тест;
  - команда `report`;
  - формат «Что нашли тесты».
- **Обвязка агента:**
  - запреты на команды через `permissions`;
  - раздел о субагентах.
- **Tauri:**
  - детерминированное ядро и чек-лист новой команды ядра;
  - сценарии через каждый адаптер;
  - раздельные папки сборок;
  - локальный сервер только на `127.0.0.1`;
  - одна CSP для веба и приложения;
  - никаких тегов вместо версий в зависимостях.

## v0.1 · 2026-10-15

Первая версия. В основе — практики двух личных проектов автора:

- уровни абстракции и тест «что это переживёт»;
- один факт — одно место;
- вниз гипотезами, вверх находками;
- дословный журнал;
- бюджет вопросов;
- «Сейчас» как единственное место статуса;
- чек-лист закрытия;
- гармонизация;
- демо-мир в тестах.

По итогам [обзора](research/2026-10-15-landscape.md) добавлено:

- размер задачи (мелочь / изменение / большой шаг) и вес процесса по нему;
- проверка строителем перед большим шагом;
- вопросы с рекомендуемым ответом;
- фильтры допуска для решений и уроков, «самое узкое долговечное место»;
- пометка «заменено» вместо правки старых решений;
- находки в виде дельты к модели;
- порог успеха («правы, если…») и аппетит в карточке;
- вертикальные срезы;
- раздел «Не должно измениться» для багов;
- защита тестов от ослабления, мутационный прогон на вехах;
- ретро среды при закрытии;
- тонкий AGENTS.md (до ~150 строк), правила из настоящих ошибок, хук на старте сессии, механическая проверка документов (`check-docs.mjs`).
