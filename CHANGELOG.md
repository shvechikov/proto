# Изменения метода

## v0.1 · 2026-10-15

Первая версия. В основе — практики двух личных проектов автора:

- уровни абстракции и тест «что это переживёт»;
- один факт — одно место;
- вниз гипотезами, вверх находками;
- дословный журнал;
- бюджет вопросов;
- «Сейчас» как единственное место статуса;
- чек-лист закрытия;
- гармонизация;
- демо-мир в тестах.

По итогам [обзора](research/2026-10-15-landscape.md) добавлено:

- размер задачи (мелочь / изменение / большой шаг) и вес процесса по нему;
- проверка строителем перед большим шагом;
- вопросы с рекомендуемым ответом;
- фильтры допуска для решений и уроков, «самое узкое долговечное место»;
- пометка «заменено» вместо правки старых решений;
- находки в виде дельты к модели;
- порог успеха («правы, если…») и аппетит в карточке;
- вертикальные срезы;
- раздел «Не должно измениться» для багов;
- защита тестов от ослабления, мутационный прогон на вехах;
- ретро среды при закрытии;
- тонкий AGENTS.md (до ~150 строк), правила из настоящих ошибок, хук на старте сессии, механическая проверка документов (`check-docs.mjs`).
