# proto — правила для ИИ-агентов

Это репозиторий **метода**, а не проект. Если тебя попросили начать новый проект по этому методу или подключить его к существующему, тебе нужен [START.md](START.md), а не этот файл.

Этот файл — для работы над самим методом.

## Что где

- `method/` — слой 1: метод, независимый от агента и стека. При онбординге копируется в `docs/method/` проекта.
- `agent/` — слой 2: обвязка агента. `instructions.md`, skills и `check-docs.mjs`.
- `stacks/` — слой 3: стеки. По умолчанию — `tauri2.md`.
- `templates/` — заготовки документов нового проекта.
- `START.md` — онбординг для агента. `README.md` — для людей.
- `research/` — исследования, на которых основаны решения.
- `CHANGELOG.md` — версии метода.

## Правила

- Документы — по-русски. Имена файлов — по-английски.
- **Слои не смешиваются.** В `method/` нет ни Claude Code, ни Tauri. В `agent/` нет стека.
- **Файлы метода копируются в проекты по одному** и должны читаться без этого репозитория. Markdown-ссылки — только между файлами внутри одной папки. На файлы проекта ссылаться кодом (`docs/roadmap.md`), а не ссылкой.
- **В заготовках** заполнители пишутся как `{…}`. Угловые скобки GitHub может съесть как HTML.
- **Метод живёт по своим принципам:** коротко, один факт — одно место, правило появляется, когда у него есть причина.
- **Изменение метода** — строка в `CHANGELOG.md` и номер версии в `method/principles.md`. Обоснования крупных изменений — в `research/`.
- **Перед коммитом** — `node agent/check-docs.mjs`.
