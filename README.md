# proto

**Метод и шаблон для проектов, которые делаются вместе с ИИ-агентом.**

Он для тех, кто хочет думать о продукте, а не о реализации. Это может быть опытный разработчик, а может быть человек, который никогда не писал код и решил «повайбкодить».

Агент пишет код. Метод следит, чтобы проект не превратился в бардак:

- всё важное записано, и каждый факт — в одном месте;
- любая новая сессия подхватывает работу с того места, где остановилась прошлая;
- идеи проверяются, а не просто реализуются;
- что должно выполняться всегда, проверяет машина, а не память агента.

## Как начать

Создайте пустую папку, откройте в ней ИИ-агента (Claude Code или другой, который понимает `AGENTS.md`) и напишите:

> Начни новый проект по методу из https://github.com/shvechikov/proto — следуй START.md.

Агент расспросит о цели, фокусе и рамках проекта, создаст документы и предложит первый шаг — маленький, но такой, который можно потрогать.

Чтобы подключить метод к уже существующему проекту, напишите то же самое, но «подключи метод к этому проекту». Без вашего согласия агент ничего не перестраивает.

## Три слоя

| Слой | Где | О чём | От чего не зависит |
|---|---|---|---|
| **1 · Метод** | [method/](method/) | Кто что решает, где живёт каждый факт, как подхватить и закрыть работу, как проверяются идеи | Ни от агента, ни от технологий |
| **2 · Обвязка агента** | [agent/](agent/) | Как писать инструкции для агента и что поручить машине: хуки, проверки, skills | От технологий. Рассчитано на Claude Code + `AGENTS.md` |
| **3 · Стек** | [stacks/](stacks/) | Технология по умолчанию — [Tauri 2](stacks/tauri2.md): Mac, Windows, iPhone, Android и веб из одного интерфейса | — |

[templates/](templates/) — заготовки документов нового проекта. [START.md](START.md) — порядок действий для агента.

## Главные идеи

1. **Человек решает «что и зачем», агент — «как».** Агент спрашивает только то, что может решить только автор: не больше трёх новых вопросов за сессию, и у каждого есть рекомендуемый ответ.
2. **Один факт — одно место.** Статус — только в «Сейчас», решения — в журнале решений, слова автора — в журнале сессий, дословно.
3. **Вниз — гипотезами, вверх — находками.** Работа начинается с «если…, то…» и признака успеха. Заканчивается тем, что мы узнали.
4. **Вес процесса — по размеру задачи.** Мелочь — строчка в журнале, большой шаг — карточка, проверка и срезы.
5. **Каждый шаг можно потрогать.** После каждого шага результат виден в продукте.
6. **Структура вырастает, а не проектируется.** Пустого «на вырост» не заводим.
7. **Что должно выполняться всегда — это проверка, а не текст.**
8. **Данные переживают код.** Настоящие данные никогда не попадают в тесты.

Подробно — [method/principles.md](method/principles.md).
